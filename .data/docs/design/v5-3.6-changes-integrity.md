## Decisions made here

1. Per-build values from labelled streams (`order:`, `offset:`, `tag`, `session`, `probe`, `mask:`), one
   rule for every value (§2.2).
2. Fixed `build.seed`: `buildId` as the tooling unit derives it, stated as a check value over the seed (§2.5).
3. Mask-only per-player variants; lowest-free assignment; variant modules as children of the server shard (§2.4).
4. No generated traps; declared traps are the one way; `trapHandled` for a handler on a trap (§3).
5. `unreachable` evidence `basis` 0–2 in one field (§3, §10).
6. `callerProbe.splitFrames` rejected (§4).
7. Identity result stays in `REPORT` (§4), agreeing with the wire unit's §4.5.
8. Timing: one clock (`os.clock()`), origin at the flush, one bound, sampled as §7.1 lists; challenge origin is the
   first flush after the call (§7).
9. `factor` default 0.5 derived from CF's simulated minima (§7.1).
10. Challenge `attempts` required; `deadline` reported for display, timed on `os.clock()` (§7.4).
11. `reactsTo` replaces on a second call; codes `stimulusKind`, `fieldCodec` (§7.3).
12. `decoyFrom` returns nil for a source with no live record (§8).
13. Shared-k re-encode refused as a mark (§8), with R16.
14. `canary.perViewer` default `true`; buffer suffix as u32le, string suffix as 4 base-62 digits (§9).
15. `canaryEchoed` keeps one trigger shape in both canary modes, narrow without `perViewer` (§10).
16. `variantMissing` counts from the first `WELCOME` (§10).
17. One caller code `fieldCodec` for a declared field whose codec the declaration doesn't take (`refers`, `canary`,
    `answers`, `reactsTo`), replacing `valueRefused` for `canary`.

## §6 pending measurements

All of them are in `v5.md` §10's table, each with the default the design uses until measured, plus the inbound
prices' Roblox measurement, the per-component decode cost and the refused-frame cost that this draft's bound adds.
Two items are moot and not listed: the deep-copy cost of held values and the size of per-variant decode plans
(variants hold a mask only). The `RemoteEvent` queue's existence is now documented `[refusals-rejudged-3 R1]`;
only its limits stay pending. Old-solver overload selection is replaced by field handles (§3.4, verified); its
milestone 3 proof on generated shards stays in "Pending proofs".

## Decisions made here

1. **Flush accumulator** exactly: start 1/60, cap 2/60, every flush step spends its 1/60 (§5.1).
2. **Dispatch:** no per-definition queue; `messagesUnhandled` (§5.1).
3. **Join hold:** each held message charged and released as a run of its own (bits + tail + 8 B per instance), a
   2,048-element cap and `sendDropped` cause 7 (§5.3). Found while deciding conflict #4: draft 3.5's hold let
   unlimited zero-bit messages through and its release could exceed every element burst.
4. **Inbound bound and defaults** (§7.5): CPU ≤ c_f·F + c_b·B + p(L)·E with p(L) = 2,000 + 133 L ns, an upper fit
   over every measured median; target 2 ms/s per player native, chosen; frames 60/120, bytes 8,192/16,384 B/s,
   elements ⌊1,150,000 / p(L)⌋ per schema, element burst max(W_max, 4,096). The 10% line was rejected because it
   needs reliable frame budgets below Lync's own 60 automatic flushes.
5. **One clock and origin** for every server duration, and a challenge's t_s at the first flush after the call
   (§7.3).
6. **Option codes:** `unknownCallOption`, `missingCallOption`, `callOptionRange` for every run-time options table;
   `configureRange` is replaced by `callOptionRange` before any release (milestones 1–2: 57 codes).
7. **Counter kinds** (count, level) and one counter table (§7.4).
8. **The inbound bound is a CI test** (§9), so a decoder change that raises a price fails the build.
9. **`sendDropped` evidence `bytes`** is the hold charge for held sends.

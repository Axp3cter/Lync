## Open

- **`position` as a path string.** `v5.md` §3.4: a handle "is the only way a declaration names one field", and only
  options that list *several* fields take path strings; `v5-collections.md` §8.2: `interest`'s `position` names one
  field by a path string. Either `position` takes a handle (`Net.fighters.fields.position`) or §3.4 adds
  single-field options; a design decision for the core-api and collections owners.
- **`"tickOutOfRange"` for "the frame had no ack".** The table maps `expired` to `tickOutOfRange` ("P or R older
  than the ring"), but `expired` also covers a frame with no ack at all (`ackSeq` −1, §12.3, §12.5), where no tick
  exists; C3's `OutOfRange` doesn't describe it. A split (say `ackMissing`) is the naming critic's.
- **`inbound.elements` in decode units vs §15.7.** `v5.md` §4.8/§7.5 now charge decode units (default 10,000
  provisional); §15.7's case for not charging redundant copies cites "167–406 of the 411 elements a second the
  derived default gives at L = 6", the retired per-schema element default. §15.4 now says new indices are charged
  "at the stream's decode-unit weight (`v5.md` §4.8)"; re-deriving §15.7's figure needs the copy's weight, a
  runtime/collections decision.
- **Visibility wire wording.** `v5.md` §3.3's table: "one presence bit per class field per update"; §9: "per add or
  update carrying it". Same rule; the core-api text omits adds.
- **`pvs.raysPerAxis`.** The naming table's name says rays; `v5-tooling.md` §2's unit for it is "sample points per
  axis per cell" (rays per cell pair are its fourth power). Naming critic.
- **Stream and `acked` rows missing from `v5.md`.** §14's protocol constants (H, nb, stream constants, `DEPTH`), the
  codes `ackedNewestMissing`, `streamCodecUnsupported`, `streamBytesExceeded`, `playoutDepthMissing`, the fact
  `inputCopyMismatch` and the stream counters are not yet in `v5.md` §4.6 (type 4 still "unused"), §4.9, §7.1, §7.3,
  §7.4. Not a disagreement in this file; the owning consistency units should pick them up under the names above.

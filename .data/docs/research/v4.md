# Lync v4 (4.0.3): design brief for v5

Distilled from `docs/v4-inventory.md`, `docs/v5-roblox-ts.md` and a read of the v4 tree at
`/home/user/Lync/.data/versions/one` (paths below are relative to its `src/` unless they start with
`docs/`, `test/` or `index.d.ts`). **Checked** means I ran it; **inferred** means read, not run.
Luau type claims were checked with luau-lsp 1.70.1, new solver (v4 pins 1.69.0).

## 1. v4 in ten lines

1. Typed buffer networking for Roblox, in Luau plus a hand-written `index.d.ts` for roblox-ts.
2. One shared module declares a **namespace**: `Lync.define(name, { Def = ... })`, required by both sides.
3. Three primitives: **packets** (one-way), **queries** (request with one reply), **sets** (server-owned
   records keyed by an integer id, replicated to audiences).
4. Values are packed to the bit from codec trees (`int`, `quant`, `struct`, `vec3`, `cframe`, ...).
5. Nothing is sent until `Lync.flush()`. Each flush batches everything into one frame per client per lane.
6. Lanes: a reliable `RemoteEvent` and an `UnreliableRemoteEvent` per namespace, plus a handshake remote.
7. The handshake compares a 64-bit FNV-1a hash of the schema descriptor. A mismatched client is refused.
8. Lifecycle: `define`* → `start()` once per side → `flush()` every frame → `close()` on the server.
9. Size: 70 modules and **13,995 lines** of `src` (the inventory's "about 17k" is wrong; `wc -l`),
   about 25k lines of tests (781 declarations, Lune), 1.2k of bench, and 19k of vendored typedefs.
10. The architecture is a closure-composing schema compiler (`shape/`, 5.4k lines) plus a run/block
    outbox (`channel/`) and a columnar set-replication engine (`state/`, 3.1k lines).

## 2. Public API surface

The export table (`init.luau`) is frozen and holds **39** names (the inventory says 38). Lifecycle:
`define start flush close`. Primitives: `packet query replicate group`. Offline: `encode decode`.
Sentinels: `all except none`. Logging: `onLog console`. Codecs: `empty bool int quant angle f32 f64
vlq vli str buffer struct array map optional tagged enum bitfield vec2 vec3 cframe rotation color3 inst`.
Type functions live in a separate module, `Lync.Types` (`Types.luau` returns `nil`), because Luau
cannot re-export a type function. Every definition handle also has `:describe()` (descriptor text).

### 2.1 Declaring (Luau, from `docs/guide/*.md`)

```lua
-- ReplicatedStorage/Net.luau
local Lync = require(ReplicatedStorage.Lync)
return Lync.define("combat", {
    Ping   = Lync.packet(Lync.empty()),
    Strike = Lync.packet(Lync.vec3(Lync.quant(-512, 512, 0.1))),
    Aim    = Lync.packet(Lync.vec3.unit(1)):newest(20),          -- lossy, latest per recipient
    Steps  = Lync.packet(Lync.vec3()):unreliable():timestamped(),
    Sell   = Lync.query(
        Lync.struct({ item = Lync.enum({ "sword", "shield" }) }),
        Lync.struct({ sold = Lync.bool(), earned = Lync.int(0, 1000000) })),
    Fighters = Lync.replicate(Lync.struct({
        name  = Lync.str(1, 20),
        team  = Lync.enum({ "red", "blue" }),
        hp    = Lync.int(0, 100),
        pos   = Lync.vec3(Lync.quant(-512, 512, 0.1)):newest(10),  -- newest field: lossy, 10 Hz cap
        title = Lync.optional(Lync.str(0, 16)),
    })):keyBy("team"),
})
```

Packet modifiers `:unreliable()`, `:newest(hz?)`, `:timestamped()` **mutate the handle** and return it
(`api/Packet.luau:65-88`); `unreliable` and `newest` are exclusive. Codec modifiers copy.

### 2.2 Using (Luau)

```lua
-- both sides
Lync.start()                                             -- client: yields on WaitForChild (Transport:74)
RunService.PostSimulation:Connect(function() Lync.flush() end)  -- NOT :Connect(Lync.flush): dt = budget, throws
game:BindToClose(Lync.close)                             -- server

-- packets
Net.Strike:onServer(function(pos, player) Net.Hit:fireClient(player, 25) end)
Net.Hit:onClient(function(damage, sent?) end)             -- sent only when :timestamped()
Net.Strike:fireServer(Vector3.new(10, 0, 4))
Net.Notice:fireClient(Lync.except(redTeam), "hi")         -- recipients: all | Player | {Player} | Group | except(...)

-- queries: one responder per side, registered BEFORE start
Net.Sell:onServer(function(req, player) return { sold = true, earned = 100 } end)
local ok, reply = Net.Sell:request({ item = "sword" })    -- client: yields; ok=false → reply is a code
Net.Confirm:request(player, { text = "rematch?" }, function(ok, reply, detail) end, 5)  -- server: callback

-- sets (server writes after start; both sides read)
Net.Fighters:add(player.UserId, { name = player.Name, team = "red", hp = 100, pos = Vector3.zero })
Net.Fighters:update(player.UserId, { hp = 90, title = Lync.none })   -- partial; none clears optional
Net.Fighters:remove(id); Net.Fighters:clear()
Net.Fighters:audience("red", redGroup)                    -- keyed sets only; unassigned key → nobody
Net.Fighters:onAdded(function(id, rec) end)               -- add, join, or gaining sight
Net.Fighters:onChanged(function(id, rec, old) end)
Net.Fighters:onRemoved(function(id, cause) end)           -- "removed" | "cleared"
for id, rec in Net.Fighters do end; print(#Net.Fighters, Net.Fighters:get(id))  -- get = live internal table

-- groups, offline codec, logging
local g = Lync.group(); g:add(p); g:remove(p); g:has(p); #g; for _, p in g do end; g:destroy()
local bytes, refs = Lync.encode(codec, value); local v = Lync.decode(codec, bytes, refs)
Lync.onLog(function(kind, message, data) end); Lync.console:disconnect()
```

Ordering rules: every `define` before `start`; responders before `start`; listeners any time (handles
replay listeners attached before `start`, `runtime/Handles`); all sends after `start`. Wrong-side
listeners **warn and attach nothing** (`api/Packet.luau:29-44`) so one shared module can wire both;
wrong-side sends throw. Query outcomes: `timeout | unanswered | leave | shutdown`; a request never
throws once sent; default timeout 10 s. Flush order inside a frame: replies, requests, packets, set
changes (so a request can overtake a packet fired earlier in the same frame).

### 2.3 roblox-ts (`index.d.ts`, 265 lines, hand-written; `docs/reference/roblox-ts.md`)

```ts
import Lync from "@axpecter/lync";   // tsconfig typeRoots must include node_modules/@axpecter
const Fighter = Lync.struct({ owner: Lync.vli(), name: Lync.str(1, 20), score: Lync.int(0, 1_000_000) });
type Fighter = Lync.Infer<typeof Fighter>;                  // { owner: number; name: string; score: number }
const Net = Lync.define("arena", {
    Fighters: Lync.replicate(Fighter).keyBy("owner"),
    Who: Lync.packet(Lync.inst<Player>("Player")),
    Sell: Lync.query(Lync.struct({ item: Lync.enum(["sword", "shield"]) }), Lync.bool()),
});
Lync.start();
RunService.PostSimulation.Connect(() => Lync.flush());
Net.Fighters.audience(player.UserId, player);              // K typed from keyBy field; error on unkeyed set
Net.Fighters.add(player.UserId, { owner: player.UserId, name: player.Name, score: 0 });
for (const [id, rec] of Net.Fighters.entries()) print(id, rec.name);   // # → size(), for-in → entries()
const [ok, reply] = Net.Sell.request({ item: "sword" });   // LuaTuple<[true, R] | [false, code, data]>
```

Differences from Luau: dot calls (`this:` typed), `size()`/`entries()`/`players()` instead of
`#`/`__iter`, `LuaTuple` multi-returns, `Map<K, V>` for `map`, `Lync.Update<T>`, `inst<T>(className)`.

## 3. Codec catalogue (as implemented; costs from code, `shape/` and `codec/`)

`width(n)` = bits to hold `n`. Leaves ≤ 24 bits pack into a shared bit word; wider leaves take whole bytes.

| Codec | Luau type returned | Wire cost / behaviour |
|---|---|---|
| `bool()` | `Codec<boolean>` | 1 bit |
| `int(min, max)` | `Codec<number>` | `width(max-min)` bits; fractions refused; > 2^53 steps refused at start |
| `quant(min, max, step)` | `Codec<number>` | `width(steps)` bits, rounds to nearest step; values slightly outside are **clamped**, not refused |
| `angle(deg)` | `Codec<number>` | `360/deg` grid (`angle(1)` = 9 bits), input mod 360; `deg` must divide 360 (checked at start) |
| `f32()` / `f64()` | `Codec<number>` | 4 / 8 bytes; NaN/inf pass |
| `vlq()` / `vli()` | `Codec<number>` | LEB128-style 7-bit groups, 1–8 bytes; `vli` sign in bit 0 (zigzag-like); ±(2^53-1) |
| `empty()` | `Codec<nil>` | 0 bytes; whole packet/query payload only |
| `str(min, max)` | `Codec<string>` | count in `ceil(width(max-min)/8)` bytes (0 if min = max) + raw bytes; inside a struct, a count ≤ 24 bits moves into the bit word |
| `str.alphabet(sym, min, max)` | `Codec<string>` | same count + `width(#sym-1)` bits per char (hex at 4 bits) |
| `buffer(min, max)` | `Codec<buffer>` | as `str` |
| `struct(fields)` | **`Codec<any>`** | fields in sorted-name order in 4 regions: presence bits + moved counts, packable bit fields, fixed bytes, variable; fixed nested structs dissolve into the parent; unknown fields refused |
| `array(el, min, max)` | `Codec<{T}>` | count + packed bit run if `el` is one unchecked grid leaf, else byte-aligned elements |
| `map(k, v, min, max)` | `Codec<{[K]: V}>` | count + pairs sorted by encoded key bytes; reader demands strictly ascending; `inst` keys refused |
| `optional(c)` | `Codec<T?>` | presence bit in the record word (1-bit word at top level); not directly inside array/map/optional/vec/cframe |
| `tagged(field, {name = struct})` | **`Codec<any>`** | tag in `ceil(width(n-1)/8)` **whole bytes** (0 for 1 variant), then variant; variants must be structs without `field` |
| `enum(names)` | **`Codec<string>`** | `width(n-1)` bits; names sorted, so wire index = sorted position |
| `bitfield(names)` | `Codec<{[string]: boolean}>` | 1 bit per (sorted) name |
| `vec2(c?)` / `vec3(c?)` | `Codec<Vector2/3>` | 2/3 × f32 by default; narrow component → leaves join the bit word |
| `vec3.unit(deg)` | `Codec<Vector3>` | octahedral, 2 × `width(floor(180/deg))` bits (16 bits at 1°); normalizes |
| `rotation.quat(deg)` | `Codec<CFrame>` | smallest-three: 2-bit tag + 3 × `width(floor(180/deg))` (29 bits at 0.5°) |
| `rotation.none()` | `Codec<CFrame>` | 0 bits |
| `cframe(pos, rot)` | `Codec<CFrame>` | each part laid out on its own, byte aligned (no cross-part bit packing) |
| `color3()` / `color3.rgb565()` | `Codec<Color3>` | 12 bytes / 16 bits |
| `inst(class?)` | `Codec<Instance?>` | varint slot (0 = nil) into a per-block sidecar array sent as the remote's 2nd arg; `IsA` both ends; unseen → nil |

**Modifiers** (`codec/Base.luau:154-200`, each copies): `:validate(fn(v, ctx) -> string?)` runs on
arrival and in `decode`, never on send; ctx `{ player, now, last }` is reused; `:as(lift, lower)` is the
only custom-type path (composes); `:newest(hz?)` only on a set's top-level field.
**Missing** (v5 gap list, by reading): no Roblox `Enum` codec, no UDim/UDim2/Rect/NumberRange/
ColorSequence/BrickColor/DateTime/Vector3int16, no tuple, no recursive or self-referential schema, no
literal/const codec, no fixed-point other than `quant`, no dictionary-with-string-key shorthand.

## 4. Wire protocol and batching

- **Remotes:** `ReplicatedStorage.LyncRemotes/<namespace>/{handshake, reliable, unreliable}`; server
  parents the folder last; client `WaitForChild` with no deadline. Every fire is `(buffer, sidecar?)`.
- **Handshake:** client hello = 8-byte FNV-1a hash of the descriptor; verdict = 9 bytes (accept: 1 +
  f64 epoch; reject: 0 + server hash). Descriptor text (`space;name=frame;…`, sorted) includes validate
  *marks* but not lift/lower or any protocol/layout version. Only hashes travel, so a mismatch cannot
  say what differs. Before the verdict a client holds up to 64 reliable frames and drops lossy ones.
- **Frame:** no frame header; concatenated blocks. Block = definition id in `width(defs-1)` bits (ids by
  sorted name; a query takes two consecutive ids) + form-specific header (`shape/Frames.luau`):
  - *running* (plain/unreliable packets): count of payloads in the spare bits up to the id's byte
    boundary, so a run holds up to `2^spare` payloads; when the id width is a multiple of 8 (incl. 0)
    a whole extra byte is spent (`Frames.running`, defect 9);
  - *stamped*: id + 24-bit ms stamp, never runs (one block per fire);
  - *newest*: id + 16-bit sequence (+ stamp);
  - *request run*: 16-bit first id then varint deltas; *response*: 16-bit id + 1-bit outcome;
  - *set section*: id + 2-bit kind (keyframe, delta, removal, clear); *set stream* for newest fields.
- **Runs:** consecutive fires of one definition to the same recipient on the same lane append to an
  open run written straight into `link.pending`; the header is written last
  (`runtime/Session.luau:207-241`). Any other send seals the run first, so order is preserved.
- **Blocks and queues:** a sealed run becomes a refcounted `Block` with a class (response, request,
  packet, establish, delta). `Link` keeps shared and per-client ("divergent") buckets, each with a lossy
  twin (`channel/Link.luau`). Recipients resolve when the run closes, not at flush (defect 33).
- **Flush** (`Session.flush`, `:698`): seal open run → budget → sweep query deadlines → newest packets
  (hz gate, encode, skip if bytes equal last send) → set audience diff → shared set plan → per-client
  catch-up → `Outbox.fire` → client-side settle. Reliable: blocks merged by class then sequence, split
  between blocks at 1,000,000 bytes. Lossy: split between blocks at 1000 bytes. `FireAllClients` only
  when no client has private blocks and no unadmitted player is present; otherwise one frame per
  admitted client (`channel/Outbox.luau:142-150`).
- **Per-player:** private blocks (targeted fires, replies, catch-up) force per-client frame assembly for
  everyone that flush; packets to a joining client are dropped; server requests to it end `unanswered`.
- **Sets** (`state/`): one partition per key value (`{store, dirt, streams}`); columnar sections
  (`state/Sections.luau`): keyframe = slot run + id steps + 2-bit generations + every field; delta =
  fieldset (list or 64-bit mask form) + slots + changed columns, wide (≥ 8 bit) non-newest grids sent as
  a difference against history; removal = slots only; clear = partition only. Coalescing within a
  flush: update+update = one, add+remove = nothing, add+update = one add, remove+add = removal + keyframe.
  Newest fields go on streams with u16 sequence and 2-bit generations. Late joiners/new viewers get
  catch-up keyframes; history is not replayed.
- **Budget:** `max(32768 B/s × dt, 1024)` for set state only, one budget per **namespace** flush (docs
  say per client), first section always goes, first refusal stops later partitions, no carry-over.
- **Timestamps:** 24-bit ms against the namespace epoch, wraps every 4.66 h; client claims clamped to
  `[arrival-60 s, arrival]`.

## 5. Performance architecture

- **"Codegen" is closure composition, not source generation** (no `loadstring`). `shape/` lowers a codec
  cell tree to a 15-kind IR (`Lower`, `Ir`), plans bit windows (`Words`, `Regions`, `Grid`), then
  `shape/emit` builds `write(b, pos, v) -> pos` / `read(b, pos, ctx) -> (pos, v)` closures, picking
  specialized variants at build time (e.g. `Block.group` has a `plain` fast path for all-required,
  non-nested records, `shape/emit/Block.luau:181-209`; `Word.emit` has a lone-field path).
- **Inner loops are table-driven**: a struct write loops over `keys[]`/`writes[]` arrays and calls a
  child closure per field; word packing loops over `slot/offset/span/shift` arrays with `bit32.extract`
  /`bor`/`lshift` (`shape/emit/Word.luau:141-175`). No per-schema straight-line code exists, so every
  field costs an indirect call plus array reads. `--!native` is set only on `shape/emit/*`, `shape/Words`,
  `wire/Bytes`, `wire/Varint`.
- **Reads allocate**: each record is `table.clone(blank)` of a pre-shaped key table (avoids rehash),
  nested records allocate one table each; listeners of one payload share the same decoded table (inferred).
- **Buffers**: one reusable `pending` and `scratch` buffer per namespace sized to the widest block.
  Sealing a block **allocates an exact-size buffer and copies** (`wire/Bytes.luau:144-148`); assembling a
  frame **allocates again and copies every block** (`channel/Outbox.luau:68-75`). With any divergence,
  shared blocks are copied once per client. Block records are pooled; buffers are not.
- **Receive**: one `pcall` per frame (`Session.luau:407`) and one per payload decode
  (`runtime/Boundary.luau:175`); listeners run on pooled coroutines (`kernel/Threads.luau`), one thread
  per listener per run of payloads.
- **Slow spots** (by reading): set writes are validated by dry-encoding each field under `pcall`
  (`state/Sync.luau:142`); each `audience()` call validates the key by encoding into a fresh buffer
under `pcall` (`state/Sync.luau:581`; per call, not per flush);
  newest set fields do a full slot scan every flush; `:as` lowers usually allocate a table per encode;
  the "never flushed" detector spawns a `task.delay(1)` per arming (`Session.luau:287`); closures carry
  scratch in upvalues so they are not re-entrant.
- **Bench**: 41 rows in 7 suites (Compile, Roundtrip, Primitives, Throughput, Fanout, Deltas,
  Replication), min-of-5 batches, ns/op + gcinfo allocation + wire bytes. **No numbers are recorded
  anywhere** (`bench/baseline.json` never written; release workflow discards output), and Lune's loader
  disables native codegen, so any number would not be Roblox's.

## 6. Typing

**Luau** (`Types.luau`; checked with a probe file):
- Inference rides a phantom `read _T: T` field on `Codec<T>`. Generic constructors carry it fine:
  `packet(int(0,3))` types the handler's value as `number`; `array(bool(),0,3)` rejects `{1}`.
- **It collapses at every record**: `struct` and `tagged` return `Codec<any>`
  (`codec/Composites.luau:36,71`), so any packet/query/set whose payload is a struct — most of them —
  gets `any` handlers, `Set<any>` writes, and unchecked `update` fields. `enum` returns `Codec<string>`
  (not the documented `"a" | "b"`), `bitfield` `{[string]: boolean}`.
- `Types.Infer`/`Schema`/`Update` are type functions in a side module. Under luau-lsp 1.70.1
  `Types.Infer<Lync.Codec<number>>` errors ("Type functions do not currently support types of the form
  *error-type*") and reduces to `never`; under the pinned 1.69.0 this is unverified. Nothing in the
  test suite type-checks consumer code, so this regression would go unseen.
- Client `request` returns `(boolean, R | OutcomeCode, OutcomeData?)`: `ok` does not narrow `reply`
  (checked: `if ok then local b: boolean = reply end` is an error).
- `keyBy(field: string)`, `audience(key: unknown, ...)`, `onChanged` gives `old: T?`, and `Packet<T>`
  exposes both sides' methods. Handles are `self: any` internally.

**roblox-ts** (`index.d.ts`): stronger than Luau — `struct` → `Schema<S>` with optional props for
`optional` fields, `tagged` → discriminated union, `enum<const T>` → literal union, `audience` key from
the `keyBy` field type (compile error on unkeyed sets), `Update<T>` refuses `Lync.none` on required
fields, `request` returns a discriminated `LuaTuple`. Weak spots: `keyBy` accepts any boolean/number/
string field while runtime allows only `bool/int/enum/vlq/vli/str` without `newest`/`as`; `tagged`
arms accept any object codec; `inst<T>(className?)` lets T and class disagree; `Packet<T>` is not side
split; `empty()` is `Codec<undefined>`, so `Ping.fireServer()` likely needs an explicit `undefined`
(inferred, untested — `test/Declaration.ts` never uses `empty`); no parity check between
`index.d.ts` and the Luau exports; TS tests compile only (9 `@ts-expect-error` lines in
`test/Rejections.ts`), nothing runs. v5 notes (`v5-roblox-ts.md` §2) add the constraints: roblox-ts
3.0.0 pins TS 5.5.3, `noAny`, `noIterableIteration`, `noMixedTypeCall`, no comment directives, so
`size()`/`entries()` adapters are unavoidable and side-split brands (remo style) are the precedent.

## 7. Extensibility

- **Custom types:** only `:as(lift, lower)` over an existing codec (doc example builds `UDim` from a
  struct). No custom leaf codec, no user bit-level writer, no registry.
- **Validation hook:** `:validate` per codec node; ctx `last` lets users hand-roll rate limits. No
  built-in per-definition rate limit (only `RESPONDER_CAP` 64 and drop-log throttling).
- **Logging:** `onLog(fn(kind, message, data))` plus the default `Lync.console` connection, which can be
  disconnected. `kind` is only `warn | error`; no info/debug/trace; `data` is shared and unfrozen; errors
  inside an `onLog` listener are not caught.
- **Introspection:** `:describe()` per handle and `encode`/`decode` offline. No metrics, byte counters,
  packet tracing, or per-namespace stats.
- **None:** no middleware/interceptors on send or receive, no plugins, no public transport or roster
  injection (both exist internally for tests: `Session.new(..., transport, roster, side)`), no
  configurable constants (all in `wire/Protocol.luau`), no custom flush scheduler (manual only).

## 8. Defects, inconsistencies, user pain

Numbers in [] are the inventory's §12 items; I confirmed the ones with a file:line.

**API/ergonomic pain**
- Luau struct payloads are untyped (`codec/Composites.luau:36,71`), contradicting
  `docs/reference/types.md` ("most code needs no annotations") and `docs/reference/codecs.md` (enum as
  `"a" | "b"`). This is the biggest gap between promise and product.
- `RunService.X:Connect(Lync.flush)` throws because dt is read as a budget (`Session.luau:128-145`);
  the overloaded `flush(budget | name, budget?)` signature is a trap.
- Manual `flush()` every frame is mandatory; forgetting it is only caught by a 1 s detector, and set
  writes do not arm it [37].
- Responders must be registered before `start`; `start` order matters; client `start()` yields forever
  if the server never creates the namespace (`channel/Transport.luau:74`).
- Packet modifiers mutate the handle while codec modifiers copy (`api/Packet.luau:65-88` vs
  `codec/Base.luau:154-200`).
- Validation rejection of a request leaves the asker waiting the full timeout, reported as `timeout`.
- `set:get(id)` returns the live internal table (mutating corrupts state); `onChanged` can fire twice
  per flush when newest and reliable fields both move.
- `tagged` spends whole bytes on the tag; `cframe` byte-aligns its parts; `quant` clamps silently [17].

**Behaviour defects**
- [1] Misuse errors carry no position: `Log.refuse`/`Log.error` use `error(msg, 0)` (`kernel/Log.luau:138-147`).
- [2] A validator or `:as` lift that throws on read is not isolated (`shape/emit/init.luau:40-51` calls
  `check` bare); it surfaces as `drop.bounds` and kills the rest of the frame.
- [3] `onLog` listener errors propagate.
- [11] Emitted closures share upvalue scratch (`slots`, `held` in `Block.group`, `Block.luau:76-77`);
  re-entrant transforms corrupt state. Module-level `parkedPath`/`wrapped` in `shape/emit/init.luau:30-35`.
- [6] Hash has no protocol/layout version: two builds with different layouts but same schema text agree.
- [22] A client flush may send newest set fields to the server, which drops them as `drop.defid`.
- [23] Server-side set listeners misfire: `onAdded`/`onRemoved` never fire on the server; an add fires
  `onChanged` with `old == new`.
- [24] Server-form request callbacks are not isolated (a throw aborts flush or leave cleanup).
- [25] An unreliable run can seal ~1024 bytes, over the 1000-byte cap; the lossy splitter cannot cut a block.
- [27] Newest packet values are held by reference (`Session.luau:636`); mutating after fire breaks every
  later flush.
- [30] Newest timestamped packets are stamped at flush, not fire. [31] Generations restart after `clear`.
- [32]/[33] Recipients resolve at run close, not at flush; malformed recipients raise late.
- [34] `start` is not atomic: `sessions[name] = session` per namespace in a loop
  (`api/Lifecycle.luau:59-72`) after `started = true`, so a later namespace's schema error leaves earlier
  ones open and `flush`/`close` index a missing session.
- [36] `close` only disconnects (`channel/Transport.luau:117-122`); remotes are never destroyed.
- [39] Budget is per namespace flush, not per client as documented.
- [4]/[12] `vec3.unit` finer than ~1.07e-5° silently becomes 3 × f32. [5] `:newest` on a set root changes
  the hash but does nothing. [7] varint reader accepts non-canonical encodings. [9] `Frames.running`
  extra byte. [10] `:validate(nil)` silently adds nothing.

**Docs vs code**: [13] `data.file/line` often internal; [14] client `drop.hello/unready` are warnings;
[15] `drop.validate` leaks `pathId/expectId/at`; [38] listeners of a run share one thread.

**Tooling/tests**: public `start` and the real `Transport` are never executed by any test [21]; 91 of 97
test files require internals; many asserts match message prose or exact bytes; real-time waits;
no coverage; no bench numbers or gate [19]; Luau type inference has no tests at all; TS typings have no
parity check; version string in four places, no changelog; the bundled luau-lsp analysis of `src`
reports 4 type errors under 1.70.1 (`kernel/Catalog.luau:78`, `state/Sync.luau:413`,
`api/Encoding.luau:31` ×2), so a toolchain bump breaks `verify`.

## 9. What is good and should survive

- **Schema-as-single-source**: one shared module, both sides require it, hash-checked handshake.
  Keep, but put a protocol version in the hash and send enough to name what differs.
- **Bit-exact packing with real range codecs** (`int`, `quant`, `angle`, `alphabet`, octahedral unit
  vectors, smallest-three quats, rgb565) and the 24-bit shared bit word with presence bits folded in.
  The compression model is the product's core value.
- **Batching model**: runs sharing a header with a count, refcounted blocks, ordering classes, one frame
  per client per lane per flush, `FireAllClients` when possible. Keep the concept; drop the double copy.
- **Three-primitive model** with sets as first-class replicated state: audiences by key, live group
  following, coalescing semantics, late-join catch-up, columnar deltas, budgeted state, newest fields.
  The semantics tables in `docs/guide/sets.md` are a good spec to carry over.
- **Delivery vocabulary**: reliable / unreliable / newest(hz) / timestamped is small and covers real
  needs; per-recipient newest with equal-value skip is genuinely useful.
- **Trust model**: values checked at the send call (throw early) and again on arrival; `:validate` with
  a sender context; validation refused on sets; server drops warn, client drops error; per-player
  log throttling; caps on in-flight requests and responders; hostile-decode test tree.
- **Query outcome codes** that never throw, and the client-yield / server-callback split.
- **Wrong-side registration warns instead of throwing**, so one shared wiring module loads on both sides.
- **roblox-ts typings that are stronger than Luau's** (`Schema`, `Update`, keyed `audience`) and the
  decisions recorded in `v5-roblox-ts.md` (hand-written `.d.ts`, adapters, side-split brands).
- **Test infrastructure ideas**: property engine with tape shrinking, a set-replication oracle, goldens
  for descriptors/frames, catalogue reachability. Keep the ideas, not the coupling to internals.
- **Layered module graph** (`kernel → wire/codec → shape/channel → state → runtime → api`) enforced by
  a script: a sound skeleton for v5, minus the order-dependent module state.
